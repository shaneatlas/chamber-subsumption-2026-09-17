## Overview

[INFERENCE] The strongest integration is not a larger command stack. It is a stable execution contract with narrow, source-bound inserts:

**Preserve the full objective → consider the full eligible repertoire → select a sufficient complementary composition → execute the next owned, authorized action → establish consumer effect → retain attributable evidence → qualify later learning → reselect when evidence changes the frontier.**

The first attachment preserves the ambition: semantic routing beyond explicitly named skills, high-leverage action, durable residual tracking, mechanical closure, and the graph-first learning hypothesis. It also contains a dated report of failures, not independent proof of present runtime state. The second attachment supplies the delivery discipline: protect consequential review, stop repetitive review, consume actionable findings, and distinguish delivery from intermediate artifacts. The recent connector records add the essential ownership boundary: a thin plugin front must not become a copy or controller of the native Source estate. [A; B, Parts I–II; C, §§1–3; D, §§1–7; E, “What this packages”]

**The optimization target is supported useful progress, not maximal invocation count, the smallest-looking patch, a predetermined approval, or an attractive completion label.**
