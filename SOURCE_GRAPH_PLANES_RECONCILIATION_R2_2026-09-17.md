## 5. Corrections that must not be lost again

### 5.1 Server version does not select the Python API

The Cypher server procedure `gds.pageRank.write` is not obsolete merely because the GDS server reports a 2.x version. Server procedure naming and installed Python-client naming are separate contracts. The typed V2 client is another interface; inspect package, object and signatures rather than inferring them from `gds.version()`. [W02; W03]

The maintainer's 2.0 changelog describes typed endpoints becoming root endpoints, removal of the `gds.v2` prefix, changed `run_cypher` retries and corrected session-delete return reporting. This is upstream migration evidence, not Source installation evidence. It reinforces the need to test retry/effect and cleanup semantics if dependencies change. [W04]

Keep raw Cypher and Python call sites explicitly distinguished. A correct existing Cypher string must not be rewritten into a Python namespace. Neither a server probe nor a script name justifies a package upgrade.

### 5.2 The simple Nornic read is not illegal Aura syntax

The Nornic maintainer cookbook lists `SimpleMatchLimitFastPath` for the simple unlabeled limit shape. It also lists mutation hot paths and generic labels that must be replaced. Those names classify implementation paths; they do not authorize a request. [W05]

Neo4j documents unlabeled MATCH as valid Cypher. Its rejection on Source Search, where confirmed, is **Source policy**, not a language prohibition. [W06]

U1's simultaneous requirements for a no-predicate fast path and a tenant predicate in every template cannot be assumed compatible. Test the actual query after policy application. In a shared store, do not remove tenant isolation to regain a fast path. In a separately isolated database, verify the owner-enforced scope rather than inventing a tenant property. Authorization to see k arbitrary records does not follow from the result cap.

Do not map a generic cookbook's EntityA or LINKS_TO onto all live domains. The reported Skill labels apply only where the actual task and schema establish them; neither placeholders nor one domain's real labels are universal replacements.

### 5.3 Correct the banner's syntax and permission claims

`SEARCH ... YIELD node, score` mixes a procedure convention into the newer subclause. The documented form attaches SEARCH to MATCH and optionally uses SCORE AS. Keep the banner non-executable until a real indexed variable and schema are bound. [W10]

Cypher 25 support and defaults must be read from the relevant configuration; the calendar year is not that configuration. New Aura organizations default to Cypher 25, while the organization setting determines created databases' language. [W11]

Even where a write clause is valid language, it is not admitted to plane A merely because the parser understands it. Split “language supports” from “this owner permits.” For Nornic, WITH EMBEDDING remains an ingestion concern, not another read-side vector-search keyword. [W13]

### 5.4 Plans are diagnostic evidence

A label scan is not sufficient to diagnose a missing RANGE index. The official plan example uses one legitimately. EXPLAIN plans rather than runs; PROFILE executes and can write. Actual row/cache measurements are not furnished by an EXPLAIN result. [W07]

Keep thresholds such as 10x or 0.90 advisory unless an actual owner contract establishes them. Bind workload, selectivity, cache temperature and missing measurement semantics. EXPLAIN does not substitute for effects/permission checks. Use plan qualification for new/changed templates or detected drift, not reflexively before every previously qualified hot-path request. Keep privileged transaction operations outside public exposure.

### 5.5 AGA cleanup depends on lifecycle and ownership

The provider documents a non-billing expired state and automatic deletion of an implicit session after its final graph is dropped. Therefore “billing continues until delete” and “graph drop never ends a session” are not universal rules. An explicit per-request session may still require explicit cleanup; verify its actual terminal state. [W08]

The documented session API separates readiness timeout from idle TTL and uses keyword-only deletion arguments. It leaves cleanup responsibility after a readiness failure with the caller. Environment credential loading is not intrinsically a laptop-only transport. [W09]

Retain resource identity before acquisition can partially succeed. Test failure before a handle returns, interruption during compute, deletion failure and recovery after hard process loss; a finally block alone cannot discharge every case. Do not delete a borrowed shared session. Source-secret injection may validly use process environment; disallow unmanaged fallback, leakage and request-time installation instead of banning a helper name.

The exact proposed connectivity method was not established by the retrieved API surface. Inspect the actual installed client. This bounded lookup does not prove the method absent from every version. [W15]

### 5.6 Preserve hygiene questions, not the pasted global scans

U1's generic-relationship and supernode queries select a broad population before counting/sorting and output LIMIT. That structure does not satisfy a bounded-input requirement. Its constraints query lists catalog data but cannot identify the exact keys used by unseen MERGE writers. [U1 L155–L183]

Keep three different diagnostics: vague relationship semantics, writer-key/constraint alignment and high-degree risk. Use real schema plus an admitted cohort or a separately authorized full census. Maintain semantic/legal proof voids as a distinct layer. A legitimate hub or generic relation is not automatically a defect. An assertion that schema visualization is always a heap bomb is not a measured finding about a particular owner.

Graph types were marked generally available in 2026.06; a preview-only rationale is stale. That does not make graph-type DDL or mirror-key type constraints part of this implementation automatically. [W12]

### 5.7 A vector pipeline is not automatically a universal route

Keep Nornic recall, optional Aura expansion and PG adjudication as an explicitly selected composition. Scope checks must precede private retrieval, not wait until the third hop. Use canonical cross-store identity mappings, not bare element IDs assumed equal across engines.

Schema fingerprints must preserve each store's identity, role/visibility, scope, timestamp and completeness; a combined digest is not an atomic cross-store snapshot. A constraints digest does not cover policy, data, template or projection state. Unknown or unreadable catalog results are not empty schemas. These are design implications of U1's proposed cross-store composition, not evidence that current Source joins are absent. [U1 L141–L151, L183]

A newly checked upstream detail is useful for the learning protocol: Nornic documents disabled vector search returning empty results plus a warning, and lazy warming with blocking startup behavior. Source's build/settings are unverified. The acceptance implication is to distinguish absent evidence from an unavailable or disabled instrument before reinforcing a lesson. [W13]

FastRP statistics or embeddings are not a kNN result. Retain any structural-neighbor experiment as a separate bounded composition over compatible vectors, and never mix it into a semantic index without its own qualified representation contract. [W14]
